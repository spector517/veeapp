# VeeApp

Веб-панель управления сервисом противодействия интернет-цензуре на базе [Xray](https://github.com/xtls/xray-core).
Фактически является графическим интерфейсом для [VeePeeNET](https://github.com/spector517/veepeenet).

> **Поддерживаемый протокол:** _VeeApp_ как и _VeePeeNET_ работает исключительно с подключениями по протоколу **VLESS + XTLS-Reality**.

```
Браузер (Vue SPA) → Nginx (:8443, TLS + Basic Auth) → Spring Boot (:9099) → sudo xrayctl (CLI)
```

## Возможности

- Управление клиентами сервиса: добавление и удаление
- Управление исходящими подключениями (outbounds): добавление вручную или по URL, редактирование, удаление
- Управление правилами маршрутизации: добавление, удаление, изменение приоритета и условий правил
- Управление стратегией разрешения доменов
- Просмотр статуса Xray, запуск, остановка и перезапуск сервиса
- Обновление гео-баз данных (geodata)
- Обновление ядра Xray до выбранной версии

## Системные требования

- **ОС:** Ubuntu 24.04+ (amd64)
- **Публичный IP-адрес** сервера
- **Открытый порт:** 8443/tcp (входящий трафик) и 9099/tcp (локальный, для бэкенда)
- **Зависимости**, устанавливаемые автоматически:
  - `nginx` - для обратного прокси и TLS
  - `fail2ban` - для защиты от атак перебором паролей
  - `openjdk-25-jre-headless` - для запуска бэкенда на Java
  - `apache2-utils` - для хранения паролей в htpasswd формате
  - `openssl` - для генерации TLS-сертификата

## Зависимости

Перед установкой VeeApp необходимо установить [VeePeeNET](https://github.com/spector517/veepeenet) версии **≥ 2.4.2** — он предоставляет утилиту `xrayctl`, которую VeeApp использует для управления Xray.

## Установка

### 1. Установите VeePeeNET

Следуйте инструкциям в репозитории [VeePeeNET](https://github.com/spector517/veepeenet).

Или используйте команду для быстрой установки:

```bash
rm -rf /tmp/veepeenet \
    && mkdir /tmp/veepeenet \
    && (cd /tmp/veepeenet \
        && curl -LO https://github.com/spector517/veepeenet/releases/download/v2.4.2/veepeenet_2.4.2_amd64.deb \
        && sudo apt install -y ./veepeenet_2.4.2_amd64.deb
    )
```

### 2. Создайте файл конфигурации

До установки пакета необходимо создать файл `/etc/default/veeapp/init.conf` с IP-адресом сервера:

```bash
mkdir -p /etc/default/veeapp
echo 'IP_ADDRESS=<ваш_публичный_IP>' > /etc/default/veeapp/init.conf
```
Без этого шага не получится сгенерировать TLS-сертификат и настроить Nginx.

### 3. Скачайте и установите пакет

Скачайте актуальный `.deb`-пакет со [страницы релизов](https://github.com/spector517/veeapp/releases) и установите:

```bash
sudo apt install ./veeapp_0.1.0_amd64.deb
```

Или используйте команду для быстрой установки:

```bash
rm -rf /tmp/veeapp \
    && mkdir /tmp/veeapp \
    && (cd /tmp/veeapp \
        && curl -LO https://github.com/spector517/veeapp/releases/download/v0.1.0/veeapp_0.1.0_amd64.deb \
        && sudo apt install -y ./veeapp_0.1.0_amd64.deb
    )
```

При установке автоматически:
- генерируются логин и пароль для входа;
- создаётся самоподписанный TLS-сертификат (EC P-256);
- настраиваются Nginx и Fail2ban;
- запускается сервис `veeapp-backend`.

## Первый вход

### 1. Откройте панель

После успешной установки откройте браузер:

```
https://<ваш_публичный_IP>:8443
```

> Браузер выдаст предупреждение о самоподписанном сертификате — это ожидаемо. Подтвердите исключение и продолжите.

Логин и пароль для входа находятся в файле `/etc/default/veeapp/init.conf`:

```bash
sudo cat /etc/default/veeapp/init.conf
```

### 2. Настройте входящее подключение

После входа перейдите в раздел **«Настройки»** и задайте параметры входящего подключения (inbound) по протоколу **VLESS + XTLS-Reality**:
- **Хост** (dest) — домен, на который будут приходить подключения от клиентов. Обычно это ваш публичный IP или доменное имя, указывающее на сервер.
- **Порт** — порт, на котором Xray будет слушать входящие подключения (рекомендуется 443/tcp).
- **Reality хост** - доменное имя, используемое в XTLS-Reality для маскировки трафика.  Иными словами это сайт, под которым будет маскироваться ваш сервер. Обычно это популярный сайт с хорошей репутацией, поддерживающий TLS 1.3 и SNI (например, `microsoft.com` для зарубежного сервера, `ya.ru` для российского сервера).
- **Reality порт** - можно не указывать, по умолчанию 443.
- **Reality names** - можно не указывать или указать значение из **Reality хост**
- **Имя сервера** - имя Вашего сервера, оно будет отображаться в имени вкладки браузера при входе на веб-панель управления.
Можно не указывать.

### 3. Добавьте клиентов

Перейдите в раздел **«Клиенты»** и добавьте хотя бы одного клиента.

> **Важно:** запуск сервиса Xray невозможен без добавленных клиентов.

После добавления для каждого клиента доступны:
- **QR-код** — для быстрого подключения с мобильного устройства;
- **ссылка для подключения** — для импорта в клиентское приложение вручную.

### 4. Запустите сервис

Перейдите в раздел **«Сервис»** и нажмите **«Запустить»**.

## Рекомендуемые клиентские приложения

Для подключения к серверу используйте приложения с поддержкой VLESS + XTLS-Reality.
Импортируйте QR-код или ссылку из раздела **«Клиенты»** веб-панели.

Рекомендованное приложение от проекта [VeePeeNET](https://github.com/spector517/veepeenet) — **[Happ](https://www.happ.su/)** (iOS, macOS, Android).
Также можно использовать любой другой клиент из [списка GUI-клиентов проекта Xray](https://github.com/XTLS/Xray-core#gui-clients).

## Безопасность

- Соединение защищено TLS 1.2/1.3 (самоподписанный сертификат EC P-256).
- Доступ к панели защищён HTTP Basic Auth.
- Fail2ban блокирует IP при 5 неудачных попытках входа за 15 минут на 1 час; при повторных нарушениях — блокировка увеличивается, макс. до 1 недели.
- Бэкенд доступен только на `127.0.0.1:9099` и не открыт наружу.

## Удаление

```bash
sudo apt purge veeapp
```

> При удалении с `purge` будут удалены учётные данные, TLS-сертификат и конфигурация из `/etc/default/veeapp/`.
